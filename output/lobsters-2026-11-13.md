## 1. 我如何意外成为百万富翁

- 原始链接: <https://lyra.horse/blog/2026/11/disinformation-machine/>
- 英文标题: How I accidentally became a millionaire

本文以第一人称讲述了网络安全研究员 Lyra Rebane 意外跻身百万富翁行列的经历。Rebane 长期专注于浏览器安全研究，此前已在 Google Chrome 等主流浏览器中报告了数十个安全漏洞，积累了相当的研究成果与声誉。2026 年 11 月 7 日，Google 因她发现 Chrome 浏览器中的一个关键安全漏洞，一次性支付了高达 1,333,337 美元的漏洞赏金（bounty），使她的个人净资产正式突破百万美元大关，她也由此成为 Google 漏洞赏金计划中单笔 payouts 金额最高的研究者之一。文章标题中的「意外」一词暗示，Rebane 本人并未将「成为百万富翁」作为职业目标，而是在持续进行安全研究的过程中，因一次高价值漏洞发现而被动实现了财富跃升。需要指出的是，原文正文信息较为有限，主要呈现为一段 AI 生成的概述性摘要，未包含 Rebane 的具体研究背景、漏洞技术细节或她本人的详细叙述，因此本文更多是一则简短的人物新闻片段，而非深度技术报道。

## 2. 《Let Over Lambda》全书现已免费在线开放

- 原始链接: <https://letoverlambda.com/>
- 英文标题: The entirety of "Let Over Lambda" is now freely available online

Doug Hoyte 所著的《Let Over Lambda—50 Years of Lisp》（ISBN 978-1-4357-1275-1，共376页）是一本深入讲解 Common Lisp 的硬核编程书籍，2008年出版以纪念 Lisp 诞生50周年。全书从基础出发，核心主题是宏（macros），即「写程序的程序」，作者认为宏是 Lisp 成为最强大编程语言的关键，能实现其他语言无法企及的抽象能力、开发效率与代码安全性。该书并非重复流行语言的常识性技巧，而是旨在拓展编程认知的边界，兼具实用性与启发性。2026年更新中，作者宣布全书以 HTML 和 PDF 格式免费在线阅读，并坦言虽个人观点已有演变，但该书作为 Lisp 教程及阐释其独特之处的作品依然成立。此外，页面新闻区记录了各章节逐步开放的过程（第4、5、6章已公开），其中第6章涉及 anaphoric 宏及一个名为 pandoric-eval 的有趣宏；该书已有日文译本在 Amazon.co.jp 上架；读者 Matthew Lamari 在 Amazon 给出5星评价。作者 Doug Hoyte 保留全部版权。

## 3. 初探 Baochip-1x：与 bunnie 的开源可信任芯片对话

- 原始链接: <https://ratfactor.com/cards/hello-baochip>
- 英文标题: Hello Baochip

本文记录了作者收到 Baochip-1x 评估板（Dabao 板）后的首次上手体验。Baochip 是硬件传奇人物 Andrew「bunnie」Huang 推出的最新开源可信任硬件项目，其 22nm SoC 集成了 RISC-V 核心、MMU、I/O 协处理器（BIO）以及 TRNG、AES 等硬件安全模块，并特意设计为可用廉价红外相机目视验证芯片结构。该芯片专为运行 Rust 编写的 Xous 微内核操作系统而打造。作者将 Dabao 板接入 Linux 电脑后，通过 USB CDC-ACM 虚拟串口以 1Mbps 速率连接 boot1 阶段的 REPL 命令行，成功执行了 echo 命令，并发现 self_destruct 命令确实会永久擦除芯片。文章还提到 Xous 生态坚持纯 Rust 工具链、避免 C 编译器带来的维护负担，同时借用 Zig 生态的 clang 编译器为 BIO 代码开发铺路。作者表示目前只需重新拾起 Rust 来点亮一个 LED，对 Xous 系统充满期待。文末感叹：如今米粒大小的芯片价格相当于一袋米，这种精密与价值远比当下流行的暴力算力更令人着迷。

## 4. Gemini网络的反营销本质：小众即价值

- 原始链接: <https://ploum.net/2026-11-12-anti-marketing-gemini.html>
- 英文标题: The anti-marketing aspect of the Gemini network

作者Ploum探讨了Gemini网络（非Google同名聊天机器人，而是先于Google命名的去中心化协议）所体现的反营销精神。他引用Eoin对Gemini网络「capsule」（相当于个人站点）数量的统计，指出一个有趣现象：每月新增capsule数量与Hacker News首页上Gemini相关推广文章数量完全无关，说明该网络的健康增长不依赖外部曝光。作者借此论证：访客数、点击量等流量指标对非营销场景毫无意义，真正有价值的创作往往数据平平，而追逐「热度」的内容转瞬即忘。他自述2013年移除博客统计后，写作反而更自由；关闭社交媒体、在Gemini上闲逛，让他得以阅读异质思想而不被反应绑架。文章还批评Hacker News首页被操纵以推广AI议题，并引用一位Mozilla资深员工离职感悟：Mozilla的卓越正源于其「不正常」，引入追求常规指标的管理者注定失败。作者呼吁建立简易Gemini托管服务并同步提供Web入口，让非技术用户也能进入这个安静、非商业、脱离时间节奏的空间。他坦然承认Gemini上「没有内容」恰恰是设计目的，小众本身就是价值所在——当现代网络乃至现实世界日益被AI和资本逻辑渗透，保留一个「怪异的小众空间」是一种正当的抵抗。

## 5. 劫持三星智能电视 Smart Hub 广告

- 原始链接: <https://dvratil.cz/2026/11/hijacking-samsung-tv-smart-hub-ads/>
- 英文标题: Hijacking Samsung TV Smart Hub Ads

作者拥有一台2022年三星智能电视，Smart Hub 界面强制推送广告，作者对此极为不满。此前通过 Pi-hole 屏蔽广告，但一次家庭网络调整导致屏蔽失效。恰逢 eMudhra CA 证书私钥泄露事件，其私钥已被加入开源工具 mitmproxy。由于三星电视不允许用户添加自定义 SSL 证书，作者借助泄露的 eMudhra 证书，在 mitmproxy 中启用 --emudhra 参数，通过 Mikrotik 路由器和 Raspberry Pi 上的 iptables 规则将电视流量透明代理至 mitmproxy，成功解密并观察电视的 HTTPS 通信。分析发现，电视在启动和返回主界面时分别向 catalyst.adgrx.com 和 tvx.adgrx.com 的 /impressions/tile 端点请求广告，响应为空 JSON 或广告描述。作者随后用 Rust 编写了一个 adspoofer 服务，拦截该端点并返回家庭照片链接替代广告，同时黑洞所有 *.adgrx.com 请求以阻断追踪。通过用泄露 CA 签发 *.adgrx.com 通配符证书、将域名解析至 NAS，实现了对电视广告的完全替换。项目已开源至 GitHub。作者指出，该方案仅在电视仍信任 eMudhra 证书期间有效，三星推送更新吊销证书后即失效，而阻止更新本身也带来安全风险。

## 8. Dyalog 21.0 版本发布：跨平台增强与 .NET 泛型支持

- 原始链接: <https://dyalog.com/dyalog/dyalog-versions/210.htm>
- 英文标题: Dyalog Version 21.0

Dyalog 21.0 于 2026 年 11 月发布，支持 Microsoft Windows 11 25H2、IBM AIX 7.3 SP4（POWER9 及以上）、Linux x86_64（基于 Ubuntu 22.04）与 ARM64（基于 Debian 13）、Apple macOS 26.3（Apple Silicon）以及 Raspberry Pi（64 位 Bookworm 系统）。该版本在用户可见功能上较为精简，重点在于为后续改进做内部铺垫，同时包含若干提升开发效率的新特性。主要增强包括：⎕DT 扩展支持文本格式日期时间的验证、解析与格式化；新增 ⎕SYSTEM 系统命名空间，提供近 50 项关于可执行文件、进程、操作系统、库版本及目录的信息；.NET 与 .NET Framework 接口均完整支持 .NET 泛型（基于 .NET 10 LTS 构建）；随附完整软件物料清单（SBOM）；配置参数可在任意位置引用其他设置值。实验性功能方面，Windows 版提供暗色模式预览，线程调度代码进行了重构以准备 v22.0 的效率与公平性改进，并引入一致性检查机制。总体而言，v21.0 是一个以基础设施和跨平台适配为主的过渡版本，亮点在于 .NET 泛型的 APL 语法支持和 ⎕SYSTEM 环境自省能力。

## 9. 「中立代码」的神话

- 原始链接: <https://foss.life/notes/2026/the-myth-of-neutral-code/>
- 英文标题: The Myth of Neutral Code

本文反驳了开发者社区中「软件正在被政治化」的流行叙事。作者指出，所谓「政治中立」的开源生态并非历史常态，而是1998年品牌重塑的产物。1980年代Stallman发起的自由软件运动以道德、伦理和反权威为内核，将软件自由视为基本社会权利；1998年「开源」概念提出、OSI成立后，刻意剥离道德与哲学话语，转而强调工程效率与商业优势，使企业界得以接受。这一「净化」持续约二十年，误导一代开发者相信技术天然去政治化。作者进一步揭示双重标准：GitHub执行美国出口管制被视为「商业现实」，而Codeberg社区投票限制AI垃圾仓库却被斥为「道德恐慌」。文章认为，当前社区重建行为准则、要求伦理问责，并非破坏中立理想，而是回归开源运动的第一原则——软件自由始终与人类价值观紧密相连。所谓「中立」本身即是一种选择，意味着优先纵容不良行为者而非保护社区安全。
